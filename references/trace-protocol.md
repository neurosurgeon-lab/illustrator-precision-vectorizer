# 描摹技术标准：从结构审计到真正的可编辑路径

## 1. 工作模式决策

| 原始来源 | 推荐策略 | 核验重点 |
|---|---|---|
| 可提取路径的 AI/SVG/EPS/PDF | 直接解析现有矢量和颜色，按语义重新组织 | 原路径、裁剪遮罩、文本、透明度和分组是否保留 |
| PNG 平涂图、线稿、图标 | 先语义分割再局部轮廓跟踪；重要曲线手动校正 | 折线噪声、孔洞、边缘抗锯齿、同色不同对象 |
| 2D 医学插画、细神经及电极 | 先每个解剖/设备部件手工勾轮廓；结构独立后填色 | 结构比例与走行、连接关系、独立导线 |
| JPEG 或带柔和明暗效果的图 | 高质量源图优先，按语义拆分，渐变/局部阴影单独重建 | 压缩伪色、光影层次、不可精确复原的纹理 |
| 照片、3D 渲染、散射复杂纹理 | 无法保证全部可编辑且逐像素一致；分部近似矢量或限制范围 | 不应虚称完成照片级精确矢量重建 |

## 2. 形状识别与对象层级

分别记录：`module > layer > object > path`。示例：

- `07_EEG_Cap` 层：`cap_base`, `cap_rim`, `cap_shadow`, `strap_left`, `strap_right`。
- `08_Electrodes` 层：每个 `electrode_01_outer`, `electrode_01_inner`, `electrode_01_contact` ...。
- `09_Cables` 层：每根 `cable_01 ... cable_N`，开放路径 + 独立描边。

共享相同色彩**不等于**同一对象；一个电极被其他结构遮挡，不能自动同其完全相同颜色的电极合并。同一可移动物件的内外多层，允许归属于一个 group，但路径依然独立。

## 3. 线稿先行

最终交付须执行 [V1.1 线条验收](line-quality.md)：逐对象对照原图检查至少 400% 放大图，原图连续线不得出现断裂、锯齿或碎线。自动蒙版和骨架追踪仅为初稿，回退多边形后仍需修复，不能直接交付。

- 使用与参考画布一致的像素坐标系统。不对原图纵横比进行重整。
- 外描线与内部划线分开；直线段以最少必要锚点表达，曲线使用贝塞尔并控制切线连续性。
- 线条优先 `fill="none"` + `stroke="#..."` + `stroke-width`、`stroke-linecap`、`stroke-linejoin`。必须呈现可变线宽时可用封闭轮廓，但标记为 shape-as-stroke。
- 复杂轮廓的自由端点、导线连入电极的位置需在 200–400% 放大下复核。
- 对纯色面与线叠合，建议额外在适当 `outline` 图层保存轮廓，避免填充和线宽无法独立修改。

## 4. 填色、阴影和颜色来源

- 颜色从源图**实际采样**，建立稳定键名与 HEX/RGBA；避免 JPEG 的色噪声导致同一设计色被误读成十几种颜色。
- 大块区域使用独立闭合路径。带孔的图形用多子路径和 `fill-rule="evenodd"` 或反向 winding，确认孔不会被填死。
- 相同真实颜色在 manifest 中使用同一标准 HEX 值，显示时不采用“肉眼差不多”替代。
- 原图仅有平涂时不使用虚构阴影；原图如有透明度/渐变，则对应独立形状+透明度或 SVG gradient，必要时标注无法完全复原的效果。
- 原图透明背景的 alpha 需保留；截图背景白色不等于原画透明，不能无依据去背。

## 5. 蒙版跟踪及限制

`scripts/build_vector_package.py` 接受逐对象二值蒙版 `mask_png`：**同原图宽高**；白色不透明=该形状，黑色=背景。它通过 OpenCV 提取轮廓生成 SVG path（带孔洞），保留独立对象。该方法有严格限制：

1. 自动形成的轮廓是可编辑的矢量多边形，**不自动等于精确贝塞尔曲线**；要求曲线光顺时请改用手工 path 或 Illustrator 调整锚点。
2. mask 仅反映可见像素，不能提供线条的中轴。导线/神经线优先 hand-drawn SVG path。
3. 边缘抗锯齿、多重透明混合可能让阈值跟踪变形；建立蒙版时应放大校正，不直接按颜色阈值当成物体标签。
4. 每个路径需归属语义对象；一张全屏色彩蒙版混入多个器官或导线时，仍不合格。
5. 如果原图存在遮挡，蒙版沿可见边界，不补出不可见真实结构。

## 6. 遮挡与文字

- 图层从后向前排列，最后绘制的对象覆盖先绘制对象；在 Illustrator 中复核其堆叠顺序。
- 不要把后方被遮挡部分用主观推断去补全。若重叠设计确需完整可拖动部件，额外建立 `inferred_hidden` 的编辑辅助路径，显式标记它非来自原图。
- 文字和数字可保留为文本（需有字体/许可与渲染差异提醒）或转真实轮廓路径（便于跨机视觉一致但失去文字编辑）。不得承诺两者同时完美。
- 真实人脸及医学患者图中禁止人为增加面部特征或与原图无关的人体结构。

## 7. 交叉验证

- 原图叠加检查：50% 不透明差异叠图；重点看头肩比例、器官外形、电极数量和线缆端点。
- 颜色检查：每个实际设计色复用标准色；阴影、背景、线稿分别评估。
- 独立编辑检查：逐个选取 `object`，改色/移动/隐藏后其他部件必须保持不变；可在复制文件上完成测试。
- 最终从实际导出的 SVG 重新渲染，而不是仅对绘图过程中的屏幕截图做比较。

## 8. v2 高精度路径与防失真规则（2026-10-29）

- **绝不以手填 `bbox` 布局**：每个对象经 CairoSVG 单独渲染为透明 PNG，在源尺寸下取真实非透明像素包围盒，自动包含 Bezier、弧线、描边和变换；精度为约 1 个源像素。原有 `bbox` 仅作诊断比对，不作为实际几何边界。
- **空几何拒绝**：只有 `M` 命令、完全透明、无有效绘制或完全画布外的对象不能算作路径对象，导出直接报错。极薄线仍可保留，只要实际产生可见像素。
- **可选平滑曲线**：`--trace-mode adaptive-bezier` 将蒙版轮廓拟合为三次 Bezier；比较候选线与原始保真折线的像素 IoU（默认 ≥0.985）及双向边缘距离 95 分位数（默认 ≤1.5 源像素），否则自动退回多边形。默认 `polygon` 追求边缘忠实，避免无条件过度平滑医学曲线。这些数值是内部曲线候选筛选，不代表与上传原图 1:1 一致。
- **颜色辅助分割**：`scripts/seed_segment.py` 允许使用经确认的种子点，从同色连通区域生成每部件的 PNG 蒙版。颜色相同的不同实体仍须分别选点；相互重叠或同色连接的部件会粘连，必须人工检查，禁止将它称为全自动语义识别。
- **关键医学区域**：在 `qa.key_regions` 中对神经、电极、导线端点等设置独立 bbox、RGB 误差阈值和改变像素比例阈值。局部不合格会使整个包失去正式交付资格，即使整图平均误差很低。
- **对象数校验**：在 `qa.required_object_ids` 和 `qa.expected_object_counts_by_prefix` 中明确要求的每根线和每个电极；缺失会中止，不得无依据推断对象数量。
- **SVG 原路径优先**：`init_project.py` 可导入简单真实矢量 SVG 的可见 `path/circle/ellipse/rect/line/polyline/polygon` 并保留 `transform`。复杂渐变、字体、剪切、滤镜、外链、栅格、CSS class、非平凡 viewBox 须先在 Illustrator 转为受支持的可编辑基础形状；不默默丢失/伪造。
- **质控分级**：结构可用 ≠ 视觉一致 ≠ 可编辑审核完成。若全图/局部阈值失败，默认阻断最终 ZIP 并留存差异图、质量报告；`--allow-draft` 仅用于人工返修的失败草稿，报告仍标 `failed`，不能交作合格成果。
- **线稿复核输出**：附加 `11_Outline_Inspection.svg`，把最终矢量路径统一显示为线稿以便人工检查曲线/锚点；它不证明在创作过程中已先描线再填色。

## 9. ROI 示例

```json
"qa": {
  "required_object_ids": ["vagus_nerve", "electrode_01", "lead_01"],
  "expected_object_counts_by_prefix": {"lead_": 3},
  "key_regions": [
    {"name": "颈段迷走神经", "bbox": [115, 100, 75, 160],
     "max_mae_rgb": 7, "max_changed_pixel_fraction": 0.08}
  ],
  "unresolved_details": ["神经轮廓与设备连接待医学复核"]
}
```

关键局部框应由原图人工确认，切勿猜测。若 ROI 内绝大多数是背景，需要进一步裁紧或增加更精细的分割对象审查。


## 10. 医学实例/中心线增强

用于替代“用一个颜色阈值当做整个身体或神经”的粗糙方案。新脚本 `medical_instance_segment.py` 接受每个部件单独的 bbox、前景/背景点、颜色容差，输出完整独立 mask 和冲突检查；`centerline_trace.py` 将神经/导线 mask 骨架化并转为真实开放描边路径，对分叉、交叉与闭环单独报告。**这些步骤并不自动理解医学解剖，也不能恢复遮挡部分。** 查看 `references/medical-segmentation-centerline.md` 了解具体用法。
