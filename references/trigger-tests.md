# 触发与非触发测试句

应触发本 Skill（显式指定或意图明确）：

- “按原图 1:1 矢量化，分图层输出 SVG/AI。”
- “帮我把脑电帽拆成皮肤、帽体、电极、每根导线各自可编辑的图层。”
- “我需要一张编号的部件分解图和完整版可编辑 SVG。”
- “只改变患者这一块的肤色色号，其他 SVG 路径和位置不动。”
- “按我的固定 Illustrator 矢量描摹工作流处理这张图。”

不应以本 Skill 替代其他任务：

- “给我原创设计一个新医学插画。”（生成新图而非原图精确追踪。）
- “帮我解释这张图中的医学概念。”（直接解释即可，除非用户提出拆解或矢量化。）
- “帮我生成一张艺术海报。”（不属于 1:1 医学科研图形描摹。）
- “帮我用 Excel 分析脑电数据。”（非 Illustrator 矢量任务。）

反馈规则：未能输出路径时如实说明，不能用文字分析替代用户明确要求的可编辑交付，也不能把 raster-in-SVG 当作矢量完成品。
